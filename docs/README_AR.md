# ملفات التوثيق الأكاديمي

- `PROJECT_DOCUMENTATION_AR.md`: التقرير العلمي والنطاق والمنهجية والنتائج والقيود.
- `MODEL_CARD_AR.md`: بطاقة النموذج والاستخدام المناسب وغير المناسب.
- `DATA_SOURCES_AND_LICENSES.md`: المصادر، حقوق الاستخدام ونسب الفضل.
- `PUBLISHING_CHECKLIST_AR.md`: قائمة مراجعة قبل رفع المشروع للعامة.
- `SCIENTIFIC_INTEGRITY_AR.md`: إيضاحات علمية عن معنى مقاييس الانحدار وإعادة استخدام الطيات.
- `index.html`: موقع المشروع التفاعلي، يمكن تفعيله من GitHub Pages باستخدام /docs.
