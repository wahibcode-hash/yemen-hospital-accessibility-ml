# قائمة التدقيق قبل نشر مستودع GitHub للعامة

- [ ] تأكد من امتلاك الإذن اللازم لإعادة توزيع المؤشرات المجمعة، وقراءة الترخيص المرفق بالنسخة الأصلية إن وجد.
- [ ] أبقِ إسناد GAIA/HeiGIT وOSM ظاهرًا، والتزم بـCC BY-SA وODbL حيث ينطبقان.
- [ ] لا ترفع كلمات المرور أو ملفات `.env` أو رموز API أو بيانات شخصية.
- [ ] افحص الملفات المراد رفعها باستخدام `python scripts/verify_repository.py`.
- [ ] تأكد أن النموذجين المحفوظين قابلان للتحميل، وأن المدخلات متوافقة مع قائمة الميزات الـ27.
- [ ] ميّز OOF التاريخي من النموذج المدرب على كامل البيانات.
- [ ] تأكد أن أسماء الملفات وروابط المصدر معروفة ومحددة.
- [ ] لا تنشر R² بوصفه «نسبة دقة».
- [ ] لا تدّعِ أن اختبارًا مستقلًا جديدًا اكتمل على الرغم من استخدام الطيات نفسها خلال التطوير.
- [ ] عند تفعيل GitHub Pages، جرّب فتح رابط الصفحة وإجراء تنبؤ حي، وتأكد من الملاحظة العلمية والإسناد.
- [ ] تحقق من أن رابط GitHub الحقيقي هو نفسه الذي سنستخدمه لاحقًا داخل Notebook Kaggle.
