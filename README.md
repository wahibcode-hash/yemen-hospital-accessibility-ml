# نموذج التنبؤ بالوصول إلى المستشفيات في اليمن

**Yemen Hospital Accessibility Prediction Model**

> مشروع ختامي لدورة تعلم الآلة ضمن برنامج إعداد مهندسي الذكاء الاصطناعي — مركز تطوير التعليم التقني والبحث العلمي، ذمار.  
> **إعداد وتطوير:** المهندس وهيب أمين عبد الجليل أحمد سعد.  
> **الإشراف العلمي:** أ.د. خالد الحسيني.

## نبذة
مشروع تطبيقي يستخدم تعلم الآلة لتقدير **نسبة السكان الذين يُقدّر أن بإمكانهم الوصول إلى مستشفى خلال ساعة واحدة** في المديريات اليمنية وفق مؤشر GAIA النموذجي لعام 2030. يوفر المشروع البيانات المصدرية والمؤشرات المعتمدة وطيات التدريب والاختبار والنماذج المحفوظة والتوثيق العلمي والواجهة التجريبية التفاعلية.

## النتائج
| النموذج | MAE (نقطة مئوية) ↓ | RMSE ↓ | R² ↑ | الوضع |
|---|---:|---:|---:|---|
| EXP_0008 | 13.4509 | 18.2778 | 0.72278 | المرجع المحفوظ |
| EXP_0012 | **12.8882** | **18.1766** | **0.72585** | مرشح تحسين استكشافي |

> **تنبيه:** النتائج OOF على محافظات مستبعدة من التدريب، لكنها لا تمثل تقييمًا مستقلاً نهائيًا بعد إعادة استخدام الطيات في تطوير النموذج. R² ليس «دقة مئوية»، والنموذج لا يقيس إمكانية الوصول الفعلية للمستشفيات ميدانيًا.

## بنية المستودع
```text
yemen-hospital-accessibility-ml/
├── data/
│   ├── original/       # 7 ملفات GAIA الأصلية قبل الاشتقاق
│   ├── processed/      # البيانات المدمجة، والميزات الـ27 المعتمدة، ومؤشرات OSM الست
│   └── splits/         # 5 طيات: تدريب مع الهدف واختبار دون الهدف وتسميات للتقييم فقط
├── models/             # نموذج CatBoost المرجعي ونموذج Logit وإعدادات الاستدلال
├── reports/            # تنبؤات OOF والمقاييس والتحليلات المحفوظة
├── src/                # كود التدريب والتنبؤ الحقيقي
├── scripts/            # فحص شامل لسلامة الملفات
├── docs/               # وثائق المشروع والواجهة التفاعلية GitHub Pages
├── notebooks/          # ملاحظة عن تعديل Kaggle المؤجل
└── tests/              # اختبارات صحة البيانات وعزل المحافظات
```

## تشغيل النموذج المحفوظ
من داخل المستودع وعلى جهاز يوجد عليه Python:
```bash
python -m pip install -r requirements.txt
python scripts/verify_repository.py
python -m src.predict --model baseline --input data/processed/selected_27_features_target_folds.csv --output outputs/predictions.csv
```

لتجربة مرشح المزج التجريبي استبدل `--model baseline` بـ`--model blend`. كلا الوضعين يستدعي نموذج CatBoost محفوظًا ويولد تنبؤات مباشرة. تستطيع إدخال بيانات جديدة إذا طابقت أعمدة الميزات الـ27؛ لا يُقرأ الهدف عند الاستدلال.

## إعادة التدريب الفعلي والتقييم
```bash
python -m src.train_evaluate
```
يُعيد تدريب EXP_0008 وEXP_0012 على طيات المحافظات الخمس، ويكتب تنبؤات ومقاييس جديدة في `outputs/` دون تعديل الملفات المرجعية. وتُحفظ جميع المخرجات في `reports/` لأغراض التوثيق فقط.

## طريقة تقسيم التدريب والاختبار
لكل طية من 1 إلى 5 يوجد مجلد مستقل يحتوي على `train_labeled.csv` و`test_features_ONLY.csv` و`test_labels_EVALUATION_ONLY.csv`. **لا يجوز تمرير ملف تسميات الاختبار إلى تدريب النموذج**. تسميات الاختبار محفوظة لكي يستطيع الباحث إعادة حساب مقاييس تقييم طياته فقط.
